## 一、语义在说什么

### 1.1 命题 = 状态集合

`PSet W := W → Prop`（`EvidenceLogic/Model/Semantics.lean`）：一个"命题"就是"在哪些状态下成立"。
`X ≤ Y` 是逐点蕴含，`⊓`／`⊔`／`ᶜ` 是逐点合取／析取／否定，`⊤`／`⊥` 是恒真／恒假。
于是**单个命题的代数结构就是 `W` 的幂集布尔代数**。

### 1.2 两层：真值索引的经典基 + 语法索引的背书框架

| 层 | 关系索引 | 作用 |
|---|---|---|
| `Base`（`Entails` 的语义） | **真值**：`suppI, refutI : PSet W → PSet W → PSet W`（任意函数） | 让经典后承 `⊢` 与代入引理成立 |
| `Frame`（`IsModel` 的语义） | **语法**：`supp : PSet W → Form → (Nat → PSet W) → Prop` | 让规则有非平凡内容（否则 P1 退化） |

`IsModel` 的 13 个字段（`nonempty`／`classical`／`agree`／`e`／`s1`／`s2`／`f1`–`f4`／`r1`／`p1`／`p2`）
**逐条**就是定稿的一条规则。这不是巧合：语义是**按规则逆推设计**的（见 [`设计说明.md`](设计说明.md) 第三节）。

### 1.3 已知的三个模型族：典范判据 · 严格蕴含 · 阈值族

```lean
suppP X Y  :=  X ≤ Y  ∨  X = ⊤  ∨  Y = ⊤                    -- Canonical.lean:40
refutP X Y :=  X ⊓ Y = ⊥  ∨  X = ⊤  ∨  Y = ⊥  ∨  Y = ⊤      -- Canonical.lean:43
```

`Canon.isModel`【已验证】说明：对**任意**非空 `W` 与**任意**原子解释 `atomRel`，
`Canon.frame W atomRel` 都是模型。工程里所有反模型都取自这一族。

**第二个族（本轮新增，`Model/Strict.lean`）**：把上面被拒绝的朴素读法本身做成框架

```lean
strictFrame:  M.supp X φ ρ := X ≤ ⟦φ⟧_base                    -- 无任何析取项
              M.refut X φ ρ := X ⊓ ⟦φ⟧_base = ⊥ ∨ ⟦φ⟧_base = ⊤
```

`strict_isModel`【已验证】证明它**也是**模型，且 `strict_transitivity_rule_valid` 证明
在这个框架里**支持传递的规则形式成立**——这正是定稿"语义不能退化为朴素蕴含读法
（否则支持传递将成为有效式）"那句设计理由的机器验证。两个族的存在说明「哪一族才对」
是**设计取舍**而非逻辑必然（详见 [`讨论与局限.md`](讨论与局限.md) 第 7.6 节）。

**第三个族（本轮新增，`Model/Threshold.lean`）**：把 `suppP` 里的 `X = ⊤` 换成**任意**固定阈值 `U`

```lean
thSuppP U X Y := X ≤ Y ∨ X = U ∨ Y = ⊤      -- U = ⊤ 时即典范判据（只差冗余的 Y = ⊥）
```

`th_isModel`【已验证】对**任意** `U` 证明它也是模型（十三字段逐一验证，**不**借助可靠性），
`th_supp_le`【已验证】随之给出**每阈值一条**的不变量

```
Derivable (p ⊳ q)  ⟹  ⟦p⟧ρ ≤ ⟦q⟧ρ  ∨  ⟦p⟧ρ = U  ∨  ⟦q⟧ρ = ⊤
```

证据学读法：**典范判据的"爆炸项"不是 `⊤` 特有的**——凡是"支持者恰等于某个固定阈值"
都能扮演同一角色。`thSuppP_not_transitive`【已验证，**零公理**】对每个 `U` 给出传递性反例，
`ThWitness.witness`【`propext`】给出 `U = {0,1} ≠ ⊤` 的具体见证：这是对
"`X = ⊤` 是唯一破坏传递性的装置"这一措辞的修正（见 [`讨论与局限.md`](讨论与局限.md) §7.7）。

## 二、逐析取项的证据学解读

这是理解全部结果的钥匙。把 `X` 读作"支持者的内容"、`Y` 读作"被支持命题的内容"：

| 析取项 | 证据学读法 | 代价／后果 |
|---|---|---|
| `X ≤ Y` | **实质读法**：证据的内容蕴含被支持命题的内容 | 单独用它会让支持传递成立（与定稿第七节冲突） |
| `X = ⊤` | 证据内容是全集／自相矛盾 ⇒ **支持一切**（爆炸） | 对应定稿第八节"自相矛盾的支持者失效" |
| `Y = ⊤` | 被支持命题是逻辑真 ⇒ **任何证据都支持它**（免费支持） | 使 S1 在 `q` 为重言式时成立 |
| `X ⊓ Y = ⊥` | 反驳的**实质读法**：证据内容与被反驳命题不相容 | 反驳的"真内容"所在 |
| `Y = ⊥` | 被反驳命题不可满足 ⇒ **免费反驳** | 使 `⊲` 在端点处退化 |
| `Y = ⊤`（反驳侧） | **反驳逻辑真也是免费的** ← 最反直觉的一条 | 正是 R1 在端点处所需（见下） |

**修正（本轮新得，已验证）**：上面"端点析取项"的说法过于粗糙。实测有**两个写出来的析取项是冗余的**
（`suppP_iff_le_or_top`、`refutP_iff_disjoint_or_top`，见 [`Structure.lean`](EvidenceLogic/Analysis/Structure.lean) 第六节）：

* 支持的**本质形式只有两项**：`X ≤ Y ∨ X = ⊤`（写出来的 `Y = ⊤` 被 `X ≤ ⊤` 吸收）；
* 反驳的**本质形式有三项**：`X ⊓ Y = ⊥ ∨ X = ⊤ ∨ Y = ⊤`（写出来的 `Y = ⊥` 被 `X ⊓ ⊥ = ⊥` 吸收）。

各析取项的分工（前半已机器验证，后半为分析）：

| 析取项 | 分工 |
|---|---|
| `X ≤ Y`／`X ⊓ Y = ⊥` | 实质读法：内容包含／内容不相容 |
| `X = ⊤` | 自相矛盾支持者爆炸（定稿第八节）；**也是唯一破坏传递性的装置**（`suppP_transitive_of_le_links` 说明"两个环节都走 `≤`"时传递成立，故 `suppP_not_transitive` 的见证必经由 `X = ⊤`） |
| `Y = ⊤`（反驳侧） | P1／P2 在 `kR = ⊲` 时所需：被反驳的内层关系式真值恒为 `⊤`。**这一条已由机器验证为"必需"**：把 `refutP` 换成去掉 `Y = ⊤` 的缩减判据后，所得框架**不是模型**（`disj_reduced_frame_not_model`，[`Disjuncts.lean`](EvidenceLogic/Analysis/Disjuncts.lean)） |

R1 只需支持侧的 `X = ⊤` 与反驳侧的 `X ⊓ Y = ⊥`／`X = ⊤`，**不需要**任何"端点"析取项。

**一个可检验的推论**：支持判据本质上是 **2** 个析取项、反驳判据是 **3** 个。这个**不对称**正是
R1 对偶（`t ⊳ ¬φ ⇒ t ⊲ φ`）**单向**破裂的语法侧对应物；事实上反向断言为**假**：

```lean
-- EvidenceLogic/Analysis/Algebra.lean
law_refut_not_dually_supp : ¬ (∀ {W} (X Y : PSet W), refutP X Y → suppP X Yᶜ)
```

（反例 `X := s0, Y := ⊤`：`refutP X ⊤` 由端点析取项免费成立，而 `suppP X ⊤ᶜ = suppP X ⊥`
要求 `X` 退化。）因此**反驳不是"支持一个否定"**——定稿第一节把 `⊲` 设为独立原语，
在语义上**有据**，而不只是记号上的选择。

**结构事实**（全部【已验证】，见 [`Structure.lean`](EvidenceLogic/Analysis/Structure.lean)）：

* 两个极端证据**既支持一切也反驳一切**：`suppP_bot_left`、`suppP_top_left`、`refutP_bot_left`、`refutP_top_left`；
* 反之，**一切证据都支持／反驳 `⊤` 与 `⊥`**：`suppP_top_right`、`refutP_top_right`（`Canonical.lean` 原有）＋
  `refutP_bot_right`、`suppP_bot_right`（后者精确地说明：**只有退化支持者才支持 `⊥`**）；
* 支持**自反**（`suppP_refl`）但**不传递**（`suppP_not_transitive`：`s0 ⊳ ⊤`、`⊤ ⊳ s1`，而 `¬ s0 ⊳ s1`）；
* 反驳**连自反都不成立**（`refutP_not_refl`：`¬ s0 ⊲ s0`）。

> **一句话**：这套语义把"证据"建成布尔代数上的一个二元关系，它只在两个**退化点**
> （空内容、全内容）处越出"内容包含／内容不容"两种实质读法；而这两个退化点又恰好是
> 让 S1／R1／P1 三条规则同时成立的必需品。

## 三、主要结果的证据学解读

### 3.1 可靠性 = 规则即闭包条件（"语义按规则逆推"）

`Derivable.soundness` 的证明是对 `Derivable` 归纳，即 `Derivable.rec`。
**语义解读**：每条规则都是模型类的一个**闭包条件**，可靠性只是说"公理系统是这套语义的内部逻辑"。
它几乎不携带"这套规则是否合理"的信息——真正有信息量的是反方向（完备性，未证）。

### 3.2 存在性 = 语义的自由性

`Canon.isModel`【已验证】对任意 `W`、任意 `atomRel` 成立。
**解读**：证据语义**不施加任何超出规则之外的一致性约束**。两面性：
不会因为语义过强而不一致；但也意味着**模型类极宽**，因此"有效 ⟹ 可推导"极难成立
（这正是 [`讨论与局限.md`](讨论与局限.md) 第 2 节的公开问题）。

### 3.3 可推导的关系陈述是"内容空洞的重言式"

三条机器事实：

* `Canon.truth_supp_is_const`【已验证】：关系式真值不随世界变化（恒为 `⊤` 或 `⊥`）；
* `derivable_rel_truth_eq_top`【已验证，见 `NonAdmissible.lean`】：**任何可推导的关系式在任意模型、任意赋值下真值为 `⊤`**；
* `derivable_rel_is_tautology`【已验证，`Structure.lean`】：同上，以 `M.Valid` 形式陈述。

**解读（本文最重要的一条）**：在这套语义里，**可推导的支持／反驳陈述作为命题是重言式**，
而它之所以为真，只能靠析取项——也就是"要么支持者内容是全集、要么被支持命题是逻辑真、
要么双方之一取极值"。由此：

* 定稿第八节的"**系统不蕴涵真**"得到语义解释：`t ⊳ φ` 可推导**并不意味着** `φ` 真；
  完全可能是 `t = ⊤`（矛盾证据）或 `φ = ⊤`（本来就真）。`not_truth_preserving`、`support_does_not_imply_truth` 都是这一点的实例；
* 定稿第九节"**关系的关系**"（`a ⊳ c`、`c ⊲ d` ⇒ `a ⊳ (c ⊲ d)`）也得到解释：
  内层关系式真值恒为 `⊤`，而**任何**证据都支持 `⊤`（析取项 3）——所以结论的成立**与 `a` 的内容无关**。

### 3.4 第十节的"非有效"与规则级非可容许性（N3）：逐条语义诊断

`NonDerivable.lean` 给出"蕴含式非有效 ⇒ 不可推导"；[`NonAdmissible.lean`](EvidenceLogic/System/NonAdmissible.lean) 给出更强的
"前提可推导、结论不可推导"（N3）。逐条的**语义根源**：

| 条目 | N3 | 语义根源 |
|---|---|---|
| 支持传递 | 未拿下 | 三个析取项使 `suppP` 只是自反关系【`suppP_not_transitive`】 |
| 反驳传递 | ✅ | 空内容支持者（`⊥`）与一切不相容 ⇒ 反驳链穿过它就丢失信息（见证取 `b := ⊥`） |
| 拆合取支持者 | ✅ | `(a∧b)` 的真值可为 `⊥`（a、b 内容不容时），而 `⊥ ≤ Y` 使"支持一切"免费；分项不然 |
| 拆全称支持者 | ✅ | `∀x p` 是对**全部命题**求交（单排序"公式即项"所致），可为 `⊥` 而实例不然 |
| 拆嵌套关系 | ✅（双向） | 内层关系式真值是**常值**；为 `⊤` 时前提免费成立、分项不然 |
| 拆反驳支持关系 | ✅（双向） | 同上，`¬(c ⊳ d)` 的真值也是常值，退化析取项接管 |
| S7 | 未拿下 | 见 3.5 |
| 反驳合取拆项 | ✅ | `Y = ⊥`／`X = ⊤` 使反驳免费，但拆出的分项内容既不空也不全 |
| 反驳全称拆实例 | ✅ | 同上（需把一元原子在模型中做成"∀ 真值非 `⊥`"才可否证） |
| 非命题性反驳逆后承 | ✅ | `t ⊲ ψ` 可由退化项免费成立，完全不含 `φ ⊢ ψ` 方向的信息 |

**筛子**【已验证，`NonAdmissible.lean` 第三节】：若结论的**支持者**真值恒为常值命题
（即内容为 `∅` 或全集），则结论在一切典范框架中有效 ⇒ 该形状的见证**原理上不可能成功**。
`canon_valid_supp_of_refut_supporter` 等三条就是这类排除。

**绕过筛子的唯一已知形态**：支持者取「**关系式 ∧ 原子**」，其真值 `⊤ ⊓ s0 = s0` 不再常值。
第九、十节的四条成功见证全部依赖这一招——这也说明 3.5 的两条不能仅凭筛子断言。

### 3.5 两条未拿下条目：把障碍翻译成证据学命题

机器事实（全部【已验证】，第十二节）：

* `suppP_middle_eq_top`：`X ⊳ Y`、`Y ⊳ Z` 而 `¬ X ⊳ Z` 三者不相容，除非 `Y = ⊤`；
* `support_transitivity_middle_truth_top`：典范框架里任何反例都**被迫**让中间公式真值为 `⊤`；
* `countermodel_formula_truth_ne_top`（任何模型）：反例处必有被支持公式真值 `≠ ⊤`。

**合并 ⇒** 支持传递的见证必须包含一个**可推导的**支持式 `b ⊳ c`，它满足
"**支持者内容是全集，而被支持命题内容不是全集**"。

**通俗翻译**：这条障碍的语义内容是一个关于证据的实质性命题——

> 若这套语义不允许"从空洞证据推出实质内容"（即 `TruthPropagation`），
> 则**支持传递作为规则是可容许的**，只是不可作为公理导出（admissible but not derivable）。

而 `TruthPropagation` 本身【本工程未证】只差 `E` 的"洞在顶层"那一支；
补齐它等价于要求"公式模 `⊣⊢` 的代数"与典范真值相合——**与完备性公开问题同源**（[`讨论与局限.md`](讨论与局限.md) 第 2 节）。
S7 侧同理：`Fin 3` 上 4096 组穷举中，唯一未被直接矛盾排除的组合恰好也要求同一传播性质。

**但"无 E 片段"的障碍现在是机器验证的定理**（[`EFree.lean`](EvidenceLogic/Frontier/EFree.lean)）。
定义去掉元规则 `E` 的推导关系 `Derivable₀`（九构造子），则可证**支持-蕴含不变量**

```lean
noE_supp_le : Derivable₀ (a ⊳ b) → ∀ ρ, M.truth a ρ ≤ M.truth b ρ
```

由此得 `noE_transitivity_valid_canon` 与 `noE_s7_valid_canon`：
**两个前提都在无 E 片段中可推导时，结论在一切典范框架中有效**。而本工程的全部反模型都取自典范框架，故

> **任何支持传递／S7 的 N3 见证，至少有一个前提不存在无 E 的推导**（它的每个推导都要用到 `E`）。

这正是全量版本唯一缺口（`E` 的"洞在顶层"）在无 E 侧的镜像；全量版本仍归约到 `TruthPropagation`。

**并且它已被严格扩张**（[`RestrictedE.lean`](EvidenceLogic/Frontier/RestrictedE.lean)）：允许 `E`，只要求每次 `E` 的
**源公式不含关系子公式**（`NoRel`），不变量仍成立（`supp_le₁_canon`，在**一切典范框架**上），
于是障碍收紧为：**见证中至少有一个前提的推导在顶层用了 `E`，且该 `E` 的源公式含关系子公式**
（即"嵌套关系重写"）。其关键论证是"洞在顶层"那一支**为空集**：
`soundness₁` 在典范框架给 `⟦φ₀⟧ = ⊤`，`φ₀ ⊣⊢ (a ⊳ b)` 在**全空基结构**给 `⟦φ₀⟧ = ⊥`，
而 `NoRel` 公式的真值与 `suppI`/`refutI` 无关（`truth_botBase_eq_canon`），两者相撞。
注意该不变量**只能对典范框架陈述**——任意模型下 `M.truth φ ρ` 与 `(Canon.base M.W M.atomRel).truth φ ρ`
**不是定义性相等**（见 [`设计说明.md`](设计说明.md) 第八节）。
**修正一处**：反驳侧的同型不变量确实**为假**，但破坏者不是 `R1`（它反而给出 `⟦a⟧ ≤ ⟦¬b⟧`），
而是 `P1` 取 `kR = ⊲, kS = ⊳`——前提只保证 `⟦a⟧⊓⟦c⟧ = ⊥`、`⟦b⟧⊓⟦d⟧ = ⊥`，
而结论第二项真值为 `⊤`，于是该断言被迫要求 `⟦a⟧⊓⟦b⟧ = ⊥`；取 `a = b = ⊤`、`c = d = ⊥` 即反例。

**（本轮新增）分量关系自由时，障碍被完全绕开且不需要任何假设。** 把定稿拒绝的朴素读法
`X ⊳ Y ⟺ X ≤ Y` 做成**第二个模型族**（[`Strict.lean`](EvidenceLogic/Model/Strict.lean)，
`strict_isModel`【已验证】），它的 `supp` 内容**没有任何析取项**；于是
`Derivable.soundness` 直接给出**全量 `Derivable`（含任意 `E`）无条件**的不变量
`strict_supp_le`【已验证】。再由"`NoRel` 公式的真值与 `suppI`／`refutI` 无关"
（`truth_noRel_congr`【已验证】，`truth_botBase_eq_canon` 是它的特例）搬到典范框架，得
`supp_le_canon_of_noRel`【已验证】——**全量 `Derivable`、零假设、代价是分量 `NoRel`**。
证据学读法：**只要"被支持命题"与"中间命题"都不谈关系（不谈"谁支持谁"），
支持就真的等于内容包含**，那个"`Y = ⊤` 免费支持"的析取项就无从发挥作用。
由此两条残余障碍被**收窄一格**（[`NoRelFragment.lean`](EvidenceLogic/Frontier/NoRelFragment.lean)）：
反模型**必须**让**结论的分量**含关系子公式（`countermodel_needs_rel`／`s7_countermodel_needs_rel`【已验证】，
中间公式 `b` 不受限），这是与"反例处中间项真值为 `⊤`"**互相独立**的另一条必要条件。

## 四、语义设计的诊断：为什么必须长成这样

三条硬约束把语义夹到唯一形态：

1. **拒绝支持传递** ⇒ 不能用朴素的 `X ≤ Y` 作为 `⊳`；破坏传递**只需**支持侧的 `X = ⊤` 一项；
2. **P1／P2 要有内容** ⇒ 关系必须**语法索引**（否则 P1 退化为与 `S`、`f` 无关的平凡条件）；
3. **P1／P2 在 `kR = ⊲` 时要成立** ⇒ 反驳侧必须有 `Y = ⊤`（被反驳的内层关系式真值恒为 `⊤`）。
   **R1 不需要**端点析取项（修正见第二节）。

因此本质判据是"支持两项 + 反驳三项"，而不是字面上的"三项 + 四项"；而"语义按规则逆推"的代价是：

* 可推导片段内容空洞（3.3）；
* `E` 与真值的相合性成为公开问题（3.5）；
* 模型族只有典范一族，反模型方法受限（筛子即其表现）；
* 规则里的 `⊢` 是语义定义的（[`讨论与局限.md`](讨论与局限.md) 第 1 节）。

## 五、类型论对应（探讨）

### 5.1 已经"机器可见"的四条对应

**(1) Curry–Howard／初始代数：可靠性就是折叠。**
`Derivable : Form → Prop` 是十个构造子的归纳族；`Frame` + `IsModel` 恰好给出该签名的一个**代数**
（每条规则一个操作）；`Derivable.soundness` 的证明就是对 `Derivable` 归纳，即 `Derivable.rec`。
用类型论的话说：**`soundness` 是初始代数到任意代数的唯一同态（折叠／catamorphism）**，
`IsModel` 的 13 个字段就是"执行这次折叠所需的数据"。因此可靠性不是一个"额外定理"，
而是 recursor 的实例化。【已验证：`Soundness.lean` 的证明结构 + `Derivable.lean` 的构造子表】

**(2) 对象语言码 + 求值函数：一个定义性解释器。**
单排序设计（公式即项）使 `Form` 成为对象语言的**码**，`Frame.truth`／`Base.truth` 成为**求值函数**，
`E` 规则（`Ctx`／`Replace`＋`plug_congr`）则是对象层的**命题外延性 + 同余**。
整体结构非常像"定义性解释器／normalization-by-evaluation"的骨架：码 → 值 → 码的等价类。【已验证：`Syntax.lean` 的 `Ctx`/`Replace`、`Soundness.lean` 的 `plug_congr`】

**(3) 定义相等 vs 命题相等的分裂。**
`Base.suppI` 以**真值**为索引（相当于"值层／定义相等"），`Frame.supp` 以**码**为索引（相当于"语法／命题相等"）。
未证的转移引理（3.5）正是两者的 **coherence／canonicity** 条件：语法层的经典等价是否与值层真值相合。
**这是本项目最重要的"类型论式"发现**：公开的完备性问题在这里表现为一条 coherence 引理。【本工程未证】

**(4) 常值子宇宙。**
`ConstTruth`（`NonAdmissible.lean` 第三节）在 `¬ ∧ ∨ →` 下封闭，且一切关系式都落在其中
——真值代数里有一个"命题层小宇宙"，支持／反驳关系只在这个小宇宙里取值。【已验证】

### 5.2 方向性猜想【猜想，无机器证据】

* 把 `t ⊳ φ` 读作"证据项 `t` 具有类型 `φ`"（justification-logic `t : φ` 风格），
  则第九节的"关系的关系"是证据的**类型化／反射**，P1／P2 是证据的**配对与概括**。
  但当前系统**没有证明项、没有依赖类型、`⊳` 也没有消去规则**，所以这只是读法而非定理；
  要落地必须**扩展**成带证明项的演算（那是系统设计，不是现有定理）。
* 更贴近现状的读法：把 `Derivable` 看作自由代数、`IsModel` 看作其实现，
  则完备性问题就是"自由代数是否被呈现完全刻画"——这属于泛代数／模型论，而非类型论的新内容。

### 5.3 `Prop` 还是 `Type`：一个被内核强制区分的承诺【已验证】

我把同一公理系统另写成 **`Type` 值呈现** `Ev`（[`Evidence.lean`](EvidenceLogic/Analysis/Evidence.lean)，
十个构造子与 `Derivable` 一一对应），并实测出一个**核层面**（而非"尚未证明"）的事实：

* `Ev φ → Derivable φ` 可定义（`Ev.toDerivable`），`Nonempty (Ev φ) → Derivable φ` 亦可（`ev_to_derivable`）；
* **`Derivable φ → Ev φ` 不可定义**：`Derivable : Form → Prop` 而 `Ev φ : Type`，
  Lean 的核**禁止**从 `Prop` 大消去（large elimination）到 `Type`。实测报错：

  ```
  error: recursor `EvidenceLogic.Derivable.casesOn` can only eliminate into `Prop`
  error(nested.lean.propRecLargeElim): Tactic `cases` failed with a nested error …
  ```

**后果**：这个选择不是风格问题，而是**实质承诺**。

* 选 `Prop`（现状）：够用于"推得出推不出"，且证明无关；但**无法在证明上做计算**
  ——没有正规形、没有可判定的 inversion、没有从证明中抽取的结构。所以
  "`Derivable` 的正向刻画"在当前呈现下**连陈述都受限**（只能在 `Prop` 层陈述存在性，
  不能抽取被断言的对象）——这正是本文 7.1 那条"缺失的工具"的**类型论根源**。
* 选 `Type`（`Ev`）：证据项成为可计算的数据。`Ev.ruleTag`（"最后一步用了哪条规则"）
  就是一个**可计算**的函数，示范了"证据项是数据"意味着什么；也只有在 `Type` 呈现上，
  才谈得上 Curry–Howard／justification-logic 的"证据项"层，以及将来的正规形与正向刻画。

因此 5.2 的猜想有一个**具体的前置条件**：要把背书逻辑做成带证明项的演算，
必须**从一开始**就用 `Type`（或 `Sort`）值的推导关系；在 `Prop` 呈现上事后补是补不回来的。

**`Ev` 这层数据呈现已经产出第一批"正向刻画"**（[`Inversion.lean`](EvidenceLogic/Analysis/Inversion.lean)）：

* `Ev.isRule : Ev φ → Nat → Prop`（按 `Ev` 结构递归的可计算判定子）与 `isE`…`isP2`；
* **紧刻画**：**原子支持者**的证据项，最后一步只能落在 `{e, s1, s2, f1, f4}`（标签 `0,1,2,3,6`），
  且这五个**真的都可达**；再模去 `s2`（沿后承转移）、`f1`（对被支持式做全称引入）、
  `f4`（对被支持式做合取引入）之后，就只剩 `{e, s1}`——即"经典后承 + 经典等价替换"。
  `f2/f3/r1/p1/p2` 各自被**形状冲突**排除（支持者沦为 `∀x p`／`a ∧ b`，或关系种类变成 `⊲`）。
* **一个被机器检查推翻的假设**：本文早期曾断言 `f1`／`f4` 也会被排除（理由是"它们改变被支持式外形"）——
  **这是错的**：约束在**支持者**上，而 `f1`/`f4` 恰恰不改支持者。反例 `f1_atomic_supporter`
  （标签 `3`）与 `f4_atomic_supporter`（标签 `6`）通过类型检查，`not_e_s1_s2_f1` 证明原命题为假。
  这正是"用数据化证据项把猜想证伪"的样本，也是 `Ev` 层的直接价值。
* **反驳侧的对偶刻画**（[`InversionRefut.lean`](EvidenceLogic/Analysis/InversionRefut.lean)）：**原子支持者**的
  **反驳**陈述，最后一步 ∈ `{e, r1, f1, f4}`（标签 `0,7,3,6`），且四个槽位**都真的可达**
  （`atom_refut_root_slots_all_realized`）；被排除的是 `s1`/`s2`（结论是 `⊳`，与 `⊲` 形状冲突）
  与 `f2`/`f3`/`p1`/`p2`（支持者沦为 `∀x p` 或 `a ∧ b`）。与支持侧同一现象：
  `f1`/`f4` 只改写被反驳式、不动支持者，故必须保留——**这一侧没有再出现被推翻的假设**。
* **链式正规形**（`SNF`）：规范、可计算长度、`s2` 下严格增长都已证；
  但把证据项**转成**正规形的函数 `snfOfAtom` 未完成——它需要在同一个函数体内同时做
  **依赖消去**（指标含 `Kind.form k …` 匹配式）与**对子项的结构递归**，Lean 4.32 会拒绝其一。
  三条可行路线（`WellFounded.fix`／手写强化消去器／把正规形改写成 `Prop` 层的 `s2⋆` 存在性）
  已写在文件注释里，**未声称完成**。

## 六、范畴论对应（探讨）

### 6.1 泛代数／代数读法（最稳、与工程现状最贴）

* 模型 = **完备布尔代数**（幂集代数 `PSet W`）＋ 一个"点敏感"的二元运算 `supp`／`refut`。
  注意它们是**用了 `⊤`（及 `⊥`）测试**的运算，因而不是纯布尔运算，而是**带指定元素的代数**。
* 自然态射 = 保持 `≤`／`⊓`／`⊔`／`ᶜ`／`⊥`／`⊤` 且与 `supp`／`refut` 交换的映射。
* `Derivable` 是签名上的**初始（自由）代数**。于是：
  **可靠性 = 每个模型都是该呈现的代数**（初始性给出唯一同态）；
  **完备性 = 呈现是否精确**（"有效"是否恰是自由代数的理论）。
  这正好解释了工程里完备性障碍的**代数形状**：Lindenbaum 代数缺所需的无穷交／无穷并（`f1`／`f2` 要求对任意交封闭）。
  【**更新**：6.1 的前半现在**已经是定理**，见 [`Initiality.lean`](EvidenceLogic/Analysis/Initiality.lean)：
  `cequiv_refl/symm/trans`（`⊣⊢` 是等价关系）、`FormQuot`（Lindenbaum 商）、
  `truthLift` + `truthLift_mk` + `truthLift_unique`（解释经商的下降与**唯一性**）、
  `soundness_as_fold`（`Derivable.soundness` 的证明被显式写成 `Derivable.rec` 应用，
  即"初始代数到任意模型代数的唯一同态"），并且
  `soundness_as_fold_eq_soundness` 说明它与 `Derivable.soundness` 是**同一个证明**。
  "完备性 = 单射性"仍只是**陈述**（`completeness_as_injectivity` 是一个未证的 `Prop`，
  且严格说单射性强于 `M.Valid → Derivable`），归约到公开问题。】

### 6.2 支持关系不是预序（机器验证的"范畴障碍"）

`suppP` 自反【`suppP_refl`】但**不传递**【`suppP_not_transitive`】；`refutP` 连自反都不成立【`refutP_not_refl`】。
**后果**：`⊳` **不能**充当范畴的 hom 关系（那需要传递性），因此"证据是态射、复合是传递"的直觉读法
在本系统里**被明确定稿拒绝**。朴素读法 `X ≤ Y` 才是预序／内蕴 hom 的读法——三个析取项正是为破坏它而加。

### 6.3 邻域／余代数类比【文献类比，部分机器验证】

把 `supp` 看成一个**邻域函数**：`X ↦ {Y : X ⊳ Y}`（"`X` 能支持哪些命题"）。则：

* 对第二分量单调【`suppP_mono`，`Canonical.lean`】= 邻域**上闭**；
* 对 `⊓` 聚合【`suppP_and`，`Canonical.lean`】= 邻域**有限交封闭**；
* 这两条恰是**单调邻域框架／证据模型**的特征，而这类框架是**单调邻域函子的余代数**，
  其（余）单子给出"单调性 + 聚合"公理，并通常还带一条 `4`／传递律（对应余单子的乘法）；
* 本系统**明确拒绝**传递（定稿第七节），即**拒绝余单子的乘法**——可以说是一个"有单位、无乘法"的退化余代数结构。
  【**更新**：这套"成立／失效"的定律清单现在**全部机器验证**，见 [`Algebra.lean`](EvidenceLogic/Analysis/Algebra.lean)：
  支持 = 自反 ＋ 对第二分量单调 ＋ 对 `⊓` 聚合 ＋ **对第一分量两个方向皆失效** ＋ **不传递**；
  反驳更贫瘠：**连自反都不成立**，第一分量两方向亦失效。传递性的失败**只**经由端点析取项 `X = ⊤`。
  这把 6.3 的"余单子缺乘法"从类比推进到可检查的代数画像。】

相关文献（本次会话只检索到条目，**未核实细节**）：
[Logical dynamics of evidence](https://dl.acm.org/doi/10.5555/2050423.2050424#1)、
[Dynamic Logics of Evidence-Based Belief](http://ai.stanford.edu/~epacuit/papers/nbhd-ev-final-rev2.pdf#4#1)、
[Strong Completeness for Iteration-Free Coalgebraic Dynamic Logics](https://ir.cwi.nl/pub/23086/23086B.pdf#8#1)、
[Positive monotone modal logic](https://portal.mardi4nfdi.de/wiki/Item:Q2243549#1)。

**必须说明的差别**：本系统的关系是**语法索引**的（以公式 `φ` 为索引，而不是对公式施加模态算子），
并且含**嵌套关系**与 P1／P2——这超出标准邻域逻辑。所以这是**类比**，不是等价。

### 6.4 纤维化／索引读法【猜想】

`Frame.supp : PSet W → Form → (Nat → PSet W) → Prop` 以**公式为索引**，
可看成"以码为底范畴、以命题代数为纤维"的**索引范畴／纤维化**；`Base` 层是把纤维商化后的"值层"。
P1／P2 是**跨纤维**的操作（把"一层的关系"搬到"另一层的关系"），
我在文献中未找到标准对应，故标为猜想。

### 6.5 一个反向观察：完备性失败源于"模型太多"

模型类的自由性（任意 `W`、任意 `atomRel`，见 3.2）意味着它是**最宽**的代数类。
因此 6.1 里的"初始代数 ⟶ 自由模型"这一比较**不可能是满的**：
完备性失败不是模型太少，而是**模型太多**。这也解释了为什么反模型法在本文里如此强大
（证"不可推导"容易）而反向（证"可推导"）几乎无路。

## 七、要把这些对应"做实"，需要做什么

1. **证或反驳 `TruthPropagation`**（= 3.5 的 coherence 引理）。这是决定「支持传递／S7 的 N3」
   与「6.1 的精确性」的主入口。（另一条已知入口是 3.5 末的**关系自由区**：
   全量 `Derivable` 在分量 `NoRel` 时**无条件**成立，见
   [`Strict.lean`](../EvidenceLogic/Model/Strict.lean) ＋
   [`NoRelFragment.lean`](../EvidenceLogic/Frontier/NoRelFragment.lean)；
   它**绕过** `TransferLemma`，但分量必须关系自由。）
2. **显式定义 `Frame` 态射**（保持 `≤`、`⊓`、`supp`、`refut` 等）并证明 `soundness` 是初始性给出的**唯一同态**
   —— 把 5.1(1)／6.1 从"读法"升级为定理。
3. **消除退化**：给一个排除 `⊥`／`⊤` 内容证据的子语义（或只允许原子支持者），
   看是否恢复传递性与真正的余单子结构；这与"定稿是否应接受传递"直接相关（见 6.3）。
4. 若要接 justification-logic 读法，需要**扩展系统**（加证明项／依赖类型）——属系统设计，不是当前定理。
