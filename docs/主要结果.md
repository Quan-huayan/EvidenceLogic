## 一、模型论两条主定理

### 1.1 可靠性

```lean
theorem Derivable.soundness (M : Frame) (hM : IsModel M) :
    ∀ {φ : Form}, Derivable φ → M.Valid φ
```

即：定稿的每条规则都在模型类中成立。证明按 `Derivable` 归纳：

| 规则 | 用到的模型条件 |
|---|---|
| E | `Frame.plug_congr`（上下文填入的真值相合性）+ `IsModel.e`（见下） |
| S1／S2 | `IsModel.classical` 把 `⊢` 化为模型内 `≤`，再用 `s1`／`s2` |
| F1／F2 | 直接是 `f1`／`f2` 的条件（前提对**所有**赋值成立） |
| F3／F4 | `f3`／`f4` |
| R1 | `r1` |
| P1／P2 | `p1`／`p2` |

其中 `Frame.plug_congr` 是 E 的关键：若 `φ`、`ψ` 在所有赋值下真值相同，
则把它们填入同一单项上下文的任意位置也得到相同真值；洞落在 `⊳`／`⊲`
**第二个**自变量时用 `IsModel.e`，落在**第一个**自变量时用真值同余。
另有辅助引理 `valid_rel`／`rel_of_valid`（及 `⊳`／`⊲` 专用版本）
在"关系成立"与"关系公式有效"之间转换。

**这是全部"不可推导性"结论的基础：有反模型 ⇒ 不可推导。**

### 1.2 典范（自由）模型族：存在性

对任意非空状态类型 `W` 与任意原子谓词解释 `atomRel`，定义

```
支持： X ⊳ φ  ⟺  X ≤ ⟦φ⟧  或  X = ⊤  或  ⟦φ⟧ = ⊤
反驳： X ⊲ φ  ⟺  X ⊓ ⟦φ⟧ = ⊥ 或 X = ⊤ 或 ⟦φ⟧ = ⊥ 或 ⟦φ⟧ = ⊤
```

则它自动满足定稿全部规则：

```lean
theorem Canon.isModel (W : Type) [Nonempty W]
    (atomRel : Nat → List (PSet W) → PSet W) : IsModel (Canon.frame W atomRel)
```

证明分工：`s1`／`s2` 由 `≤` 的传递性；`f1`／`f2` 由两条无穷交引理
（`suppP_iInter`／`refutP_iInter`／`suppP_of_iInter`／`refutP_of_iInter`）；
`p1`／`p2` 利用"内层关系为真时其真值为 `⊤`"，故外层关系由 `Y = ⊤` 这一析取项成立；
`classical` 通过与基结构 `Canon.base` 的同一性（`Canon.frame_truth`）把
`Entails` 转移到框架真值。

**设计理由**：定稿明确拒绝支持传递、反驳传递，故语义不能退化为朴素的
"`X ≤ Y` 蕴含"读法（否则支持传递成为有效式）。`X = ⊤` 解释为
"自相矛盾的支持者"——它既支持一切也反驳一切，与定稿第八节
"同一支持者若同时支持 `φ` 和 `¬φ` 会支持一切"一致；它正是打破传递性的装置。
`⟦φ⟧ = ⊤`／`⟦φ⟧ = ⊥` 则使 **R1** 成立。

## 三、定稿第十节：不可推导性（`NonDerivable.lean`）

方法：取有限模型 `W := Fin 3`、具体 `atomRel`（记作 `M3`），
用典范模型验证前提、否证结论，再由可靠性得到不可推导：

```lean
theorem not_derivable_of_countermodel {φ : Form} {M : Frame}
    (hM : IsModel M) (h : ¬ M.Valid φ) : ¬ Derivable φ
```

| 定稿条目 | 反模型实例 | 定理（成对 `_not_valid`／`_not_derivable`） |
|---|---|---|
| 支持传递 | `a=F1({0})`, `b=F0(⊤)`, `c=F2({1})` | `support_transitivity_*` |
| 反驳传递 | `a=F4({0,1})`, `b=F0(⊤)`, `c=F2({1})` | `refute_transitivity_*` |
| 拆合取支持者 | `a=F1`, `b=F2`, `φ=F2` | `and_split_*` |
| 拆全称支持者 | `p=F5(x)`, `φ=F2` | `all_split_*` |
| 拆嵌套关系 | `a=F1`, `c=F2`, `d=F1`；另一例 `a=⊥`, `c=d=F2` | `nested_supp_*`／`nested_refut_*` |
| 拆反驳支持关系 | `a=c=d=F1`（两个结论重合） | `refute_supp_*` |
| S7 不同主体合取 | `a=F0`, `b=F2`, `φ=F3`, `ψ=F2` | `s7_*` |
| 反驳合取拆项 | `t=F1`, `φ=F1`, `ψ=F2` | `refut_and_*` |
| 反驳全称拆实例 | `t=F3`, `φ=F5(x)` | `refut_all_*` |
| 非命题性反驳逆后承 | `t=F1`, `φ=F1`, `ψ=⊤`（见下） | `not_valid_refute_converse*` |

其中 `F0=⊤`、`F1={0}`、`F2={1}`、`F3={2}`、`F4={0,1}`，
`F5` 是带变元的原子（对 `X = {0}` 取 `{2}`，否则取 `{0}`），
故 `∀x F5` 的真值是 `⊥`。

**规则级非可容许性（比非有效性更强）**：

```lean
theorem and_split_not_admissible :
    ¬ (∀ a b φ : Form, Derivable ((Form.and a b) ⊳ φ) → Derivable (a ⊳ φ))
```

见证：`Derivable ((F1 ∧ F2) ⊳ F2)` 由 S1 可推导（合取消除是经典后承），
而 `Derivable (F1 ⊳ F2)` 不可推导。

**不蕴涵真**：

```lean
theorem not_truth_preserving :
    ¬ (∀ (t φ : Form), Derivable (t ⊳ φ) → ∀ M : Frame, IsModel M → M.Valid φ)
```

见证 `t = φ = ⊥`：`⊢ᴱ (⊥ ⊳ ⊥)`（S1，因 `⊥ ⊢ ⊥`），而 `⊥` 在 `M3` 中无效。

> 第十条的说明：该规则带**语义副作用条件** `φ ⊢ ψ`。由于 `Entails` 量化
> **所有**基结构（原子在基结构中任意解释），`Entails F1 F0` 并不成立；
> 因此用忠实的规则形状见证 `t=F1, φ=F1, ψ=⊤`
> （`Entails F1 ⊤` 成立、`M3 ⊨ F1 ⊲ ⊤` 成立、而 `M3 ⊭ F1 ⊲ F1`），
> 另附字面实例的不可推导性 `not_derivable_refute_converse`。

## 五、规则级非可容许性（`NonAdmissible.lean`）

第四节末提到的"强读法"在此推广。定稿第十节说这些命题"不能推出"，
`NonDerivable.lean` 给的是**公式层**读法（相应蕴含式非有效，故不可推导）；
本模块给的是更强的**规则层**读法：

```lean
¬ (∀ <参数>, Derivable <前提₁> → Derivable <前提₂> → Derivable <结论>)
```

即"该规则不是可容许规则"。方法固定两步：**前提**用 `Derivable.s1`／`.s2`／`.r1`
与 `support_refl`／`P1`／`P2` 的组合显式推出；**结论**在某个 `Canon.frame`
（有限模型）中算出不有效，再由 `not_derivable_of_countermodel`（可靠性的逆否）得不可推导。

| 定稿条目 | 定理 | 见证（支持者/结论要点） | 否证模型 |
|---|---|---|---|
| 反驳传递 | `refute_transitivity_not_admissible` | `a:=F1, b:=⊥, c:=F1`；`¬⊥` 有效故 `a⊲⊥` 一律可推导 | M3 |
| 拆全称支持者 | `all_split_not_admissible` | 前提 `support_refl`；结论 `(atom 5 [⊥]) ⊳ ∀x F5` | M3 |
| 拆嵌套关系 → `a ⊳ c` | `nested_supp_not_admissible` | `a := (F2⊲F3) ∧ F1`：真值 `⊤⊓s0 = s0` **非常值** | M3 |
| 拆嵌套关系 → `c ⊲ d` | `nested_refut_not_admissible` | 前提 `(F1⊲F1) ⊳ (F1⊲F1)`；结论 `F1 ⊲ F1` | M3 |
| 拆反驳支持关系 → `a ⊲ c` | `refute_supp_not_admissible` | `a := ¬(F3⊳F2) ∧ F3`；前提 `R1 ∘ S1` | M3 |
| 拆反驳支持关系 → `a ⊲ d` | `refute_supp_not_admissible'` | `a := ¬(F3⊳F2) ∧ F2`；前提 `R1 ∘ S1` | M3 |
| 反驳合取拆项 | `refut_and_not_admissible` | `t := ¬(F4∧F1)`：真值 `s0ᶜ`，`refutP` 四项才全落空 | M3 |
| 反驳全称拆实例 | `refut_all_not_admissible` | `t := ¬∀x F5`；需自建 `M4`（原子 5 := `X≤s0 ? s01 : s0`） | **M4** |
| 非命题性反驳逆后承 | `refute_converse_not_admissible` | `t := ¬F1∧¬F2`、`ψ := (F1∧F2)⊳F1`、`φ := ψ∧F3`；前提由 `P1` 拼出 | M3 |

**尚未拿下**：支持传递、S7（十二个子命题中的两个）。该文件第十一节给出可复核的障碍：

* 已机器复核的筛子：`derivable_rel_truth_eq_top`（可推导的关系式在任意模型真值为 `⊤`）、
  `canon_valid_supp_of_const_left`／`canon_valid_refut_of_const_left`
  （支持者真值恒为常值时结论必然有效），并据此排除 `a := c⊲d`／`c⊳d`／`¬(c⊳d)`
  等一整批见证；**但第九、十节的成功见证恰恰绕开了它**（支持者取"关系式 ∧ 原子"，
  真值非常值）——可见"支持者里出现原子"是绕开筛子的关键。
* 待形式化的不变量：`Derivable (a ⊳ b) → ∀ ρ, ⟦a⟧ρ ≤ ⟦b⟧ρ`（在每个模型成立）。
  它一旦成立，传递与 S7 的结论就分别由 `⟦a⟧≤⟦b⟧≤⟦c⟧` 与
  `⟦a⟧⊓⟦b⟧ ≤ ⟦φ⟧⊓⟦ψ⟧` 立得**有效**，即反模型方法被堵死。**该不变量在本文中尚未证明**，
  故上述两条的"非可容许"仍属未决，而**不是**已否证。

因此对这两条的准确说法是：它们**未必**"每个实例都推不出"，现有证据倾向于
它们**作为规则可容许**、只是不可作为公理导出（admissible but not derivable）。

## 六、证据语义层的结构、类型论与代数结果

`Structure`／`Evidence`／`Initiality`／`Disjuncts`／`EFree`／`Algebra`／`Inversion` 七个模块。
逐条的语义解读见 [`证据语义解读.md`](证据语义解读.md)。

### 6.1 结构事实（`Structure.lean`）

* 退化支持者：`suppP_bot_left`／`suppP_top_left`／`refutP_bot_left`／`refutP_top_left`
  —— `⊥` 与 `⊤` **既支持也反驳一切**；反之 `refutP_bot_right`、`suppP_bot_right`
  （**只有退化支持者才支持 `⊥`**）。
* 支持**自反但不传递**（`suppP_refl`、`suppP_not_transitive`、`suppP_transitive_of_le_links`）；
  反驳**连自反都不成立**（`refutP_not_refl`）。
* **判据的本质形式**：`suppP_iff_le_or_top`（本质 **2** 个析取项）、
  `refutP_iff_disjoint_or_top`（本质 **3** 个）——写出来的支持侧 `Y = ⊤` 与反驳侧 `Y = ⊥` **冗余**。
  这个 2 vs 3 的不对称正是 R1 对偶单向破裂的语法侧对应物。
* 关系式真值恒为**常值命题**（`truth_supp_is_const`、`canon_truth_supp_is_const`）；
  可推导的关系式是**重言式**（`derivable_rel_valid`、`derivable_rel_is_tautology`）。

### 6.2 析取项的必要性（`Disjuncts.lean`）

* **`disj_reduced_frame_not_model`**：删去反驳侧的 `Y = ⊤` 后，缩减判据 `refutP₀` 使框架
  **不是模型**（P1 取 `kR = ⊲, kS = ⊳` 的具体实例）⇒ 该析取项**必需**，不只是分析。
* `disj_transitivity_failure_via_top_left`：支持传递失败**只能**经由 `X = ⊤` 项。
* `disj_naive_*`：朴素读法满足支持侧规则，唯一问题是让支持传递成立（定稿第七节拒绝它的理由）。

### 6.3 `Prop` 还是 `Type`：证据项的数据化（`Evidence.lean`）

* `Ev : Form → Type`（十构造子）是同一公理系统的 **`Type` 值**呈现；
  `Ev.toDerivable`（单向遗忘）、`Ev.ruleTag`（**可计算**的数据函数）、`ev_to_derivable`。
* **核层面事实**：`Derivable → Ev` **不可定义**（`Prop` 不能大消去到 `Type`）。
  故"用 `Prop` 还是 `Type`"是**实质承诺**：`Prop` 呈现下无法做正规形／inversion 计算，
  这正是"`Derivable` 正向刻画"缺失的类型论根源。

### 6.4 初始性（`Initiality.lean`）

* `cequiv_refl/symm/trans`、`FormQuot`（Lindenbaum 商）；
  `truthLift`＋`truthLift_mk`／`truthLift_unique`（解释**经商下降**且唯一）。
* **`soundness_as_fold`**：可靠性＝显式 `Derivable.rec` 应用（初始代数到任意模型代数的唯一同态）；
  `soundness_as_fold_eq_soundness` 表明它与 `Derivable.soundness` 是**同一个证明**。
* `completeness_as_injectivity`：只作**陈述**（未证；且单射性严格强于 `M.Valid → Derivable`）。

### 6.5 无 E 片段与受限 E 片段（`EFree.lean`、`RestrictedE.lean`）

* `Derivable₀`（去掉元规则 `E` 的九构造子）＋ `noE_soundness₀`
  ＋ **`noE_supp_le`**（支持-蕴含不变量，九支全闭）。
* `noE_transitivity_valid_canon`、`noE_s7_valid_canon`：两个前提都在无 E 片段可推导时，
  结论在**一切**典范框架中**有效**。因为本工程的反模型都取自典范框架，故
  **任何支持传递／S7 的 N3 见证，至少有一个前提不存在无 E 的推导**。
* **受限 E 片段（`RestrictedE.lean`，是上者的严格扩张）**：允许 `E`，但要求每次 `E` 的
  **源公式不含关系子公式**（谓词 `NoRel`）。核心是
  `supp_le₁_canon : Derivable₁ (a ⊳ b) → ∀ρ, (Canon.frame W atomRel).truth a ρ ≤ …`
  （不变量，在**一切典范框架**上成立），由此 `transitivity_valid_canon₁`、
  `s7_valid_canon₁` 同样成立。于是障碍进一步收紧为：

  > **任何支持传递／S7 的 N3 见证，至少有一个前提的推导在顶层用了 `E`，
  > 且该 `E` 的源公式含关系子公式**（即"嵌套关系重写"）。

  关键论证（`supp_inv_false_canon`）：`E` 的"洞在顶层"那一支是**空集**——
  由 `soundness₁` 在典范框架上得 `⟦φ₀⟧ = ⊤`，由 `φ₀ ⊣⊢ (a ⊳ b)` 在**全空基结构**
  （`suppI ≡ ⊥`）上得 `⟦φ₀⟧ = ⊥`，而 `NoRel φ₀` 的真值与 `suppI`/`refutI` 无关
  （`truth_botBase_eq_canon`），两者相撞。
* **为什么只能对典范框架陈述**（本轮暴露并修正）：上述论证要把 `⊤` 与 `⊥` 撞在
  **同一个结构**上，而 `M.truth φ ρ` 与 `(Canon.base M.W M.atomRel).truth φ ρ`
  **不是定义性相等**（分别读 `Frame.supp` 与 `Base.suppI` 两个字段）；
  只有典范框架才有命题性的 `Canon.frame_truth`。任意模型版的陈述在**陈述层面**即有缺口。

### 6.6 代数画像（`Algebra.lean`，44 条）

* 头号：**`law_refut_not_dually_supp`**——`refutP X Y → suppP X Yᶜ` **为假**
  （＋结构性形式 `law_refut_top_not_supp_bot`）⇒ **`⊲` 不能由 `⊳` 与 `¬` 定义**，

  `refutP X ⊤`、`refutP ⊥ Y`、`refutP X ⊥`、`Y ≠ ⊤` 时第二分量反单调。
* 失效：支持的第一分量两个方向、传递；反驳的自反、传递、第一分量两个方向（各附具体反例）。

  `law_supp_not_mono_left_up`（`X=⊥, Y=⊥, Z=s0`）、
  `law_supp_not_mono_left_down`（`X=⊤, Y=s0, Z=s1`）、

  该端点支其实**为假**（`refutP s0 ⊤` 由端点析取项免费成立，但 `¬ refutP s0 s0`）。

### 6.7 原子支持者的正向刻画（`Inversion.lean`）

* `Ev.isRule`＋`isE`…`isP2`（可计算判定子）；**`atom_root_restricted`**：

* **正规形（已完成，`NormalForm.lean`）**：把 `s2` 链**剥干净**——

### 6.8 转移引理与边界刻画（`Transfer.lean`）

* **可证的一半**（`cequiv_rel_components_of_noRel`）：若 `u, v, u', v'` **都不含关系子公式**，则
  `((u ⊳ v) ⊣⊢ (u' ⊳ v'))` 迫使两条分量在**典范基**上真值相等。
  证法：把等价的蕴含分别实例化到两个**投影基结构**（`projBase₁`：`suppI := fst`；`projBase₂`：`suppI := snd`），
  支持式的真值在那里**定义性**化为分量真值 ⇒ 得双向 `≤` ⇒ 再用 `NoRel` 的基无关性
  （`truth_projBase₁_eq_canon`／`truth_projBase₂_eq_canon`）搬回 `Canon.base`。
  全程**不需要** `[Nonempty W]`。
* **断掉的一半**（`TransferLemma`，只作**陈述**）：去掉 `NoRel` 后，投影基与典范基对同一公式的
  真值不再一致（前者走投影函数、后者走 `suppP`），该方法失效。这正是
  [`讨论与局限.md`](讨论与局限.md) 第 2 节公开问题在关系式上的投影。
* **边界确实被占据**（`holeAtTop_source_need_not_be_supp`）：存在**非关系式**的 `φ`
  （取 `φ := (⊤ ⊳ ⊤) ∧ ⊤`）使 `Derivable φ` 且 `φ ⊣⊢ (⊤ ⊳ ⊤)`——即 `E` 的"洞在顶层"这一步的源公式
  **不必**是关系式，故 `TransferLemma` 的前提形态与那一步能提供的假设形态**不匹配**
  （`holeAtTop_step_derivable` 表明该步本身是可推导的）。
  反之 `holeAtTop_of_transferLemma` 说明：源公式**确实**是关系式时，转移可行。
  这给出「支持传递／S7 拿不下」的**精确边界**：

  > 缺口恰在 `E` 的"**洞在顶层、且源公式不是关系式**"那一支。  > （`TransferLemma` 覆盖的是"源是**分量关系自由**的关系式"的情形——注意这**不是**
  > `TruthPropagation` 的反例，只否证"源必是关系式"这条捷径。）

  **这一条后来被修正**（见 6.9）：它描述的是"投影基 ＋ 转移引理"**这条技术路线**的边界，
  而不是前沿本身。换一个 motive（把 `⊣⊢` 写进不变量）后，`E` 的"洞在顶层"**根本不在关键路径上**；
  缺口统一收敛到 `TransferLemma` 本身。

### 6.9 条件化的前沿定理（`Conditional.lean`）

把不变量改成**模 `⊣⊢`** 的形式

```
P(φ) := ∀ a b, (φ ⊣⊢ (a ⊳ b)) → ∀ρ, ⟦a⟧ρ ≤ ⟦b⟧ρ
```

则：

* **`E` 的"洞在顶层"自动闭合**：由 `φ₀ ⊣⊢ ψ₀` 经上下文填入得 `γ ⊣⊢ δ`
  （`cequiv_plug`，对 `Ctx` 的显式消去子递归，**对任意公式成立**），
  假设 `δ ⊣⊢ (a ⊳ b)` 立即给出 `γ ⊣⊢ (a ⊳ b)` ⇒ 归纳假设直接适用
  ⇒ **不需要任何相干性／相合性输入**；
* 九条规则支则**全部**需要 `TransferLemma`（经 `transfer_frame` 把 `Canon.base` 上的分量等式
  用**命题性**桥梁 `Canon.frame_truth` 搬到 frame 层）；`r1` 支用形状冲突
  `support_not_cequiv_refut`（把 `suppI` 恒取 `⊥`、`refutI` 恒取 `⊤`，`⊣⊢` 的第一个方向
  就**定义性地**是 `⊤ ≤ ⊥`）。

于是得到**条件化**结论（`TransferLemma` 是**假设**，本工程**未证**）：

| 定理 | 内容 |
|---|---|
| `supp_le_of_cequiv_canon` | `TransferLemma ⇒` 模 `⊣⊢` 的不变量（典范框架） |
| `supp_le_of_transferLemma_canon` | `TransferLemma ⇒` `Derivable` 上的支持-蕴含不变量 |
| `transitivity_valid_canon_of_transferLemma` | ⇒ 支持传递的结论在一切典范框架中有效 |
| `s7_valid_canon_of_transferLemma` | ⇒ S7 同型 |

**意义与逻辑地位**（务必分清"充分"与"必要"）：

* 所有剩余缺口——`TruthPropagation`、支持传递与 S7 的 N3、以及
  `completeness_as_injectivity` 的相干性部分——现在**由一条引理统一推出**：
  [`Transfer.lean`](../EvidenceLogic/Frontier/Transfer.lean) 的 `TransferLemma`。
* 但这条链是**充分**方向：`TransferLemma` 成立 ⇒ 上述结论整体落地；
  **反之（必要性）未知**——本工程没有证明"`TruthPropagation` ⇒ `TransferLemma`"，
  而且 `TransferLemma` 给出的是**逐分量等式**，看起来严格强于传播律。
  因此：**证出 `TransferLemma` 会正面解决前沿；反驳它则只会让现有唯一路线失效**，
  并不等于推翻"支持传递／S7 是 admissible 但不可导出"的判断。
* 这正是当前判决性尝试的两个方向（证明 / 反驳）所对应的两种后果。

### 6.10 判决性尝试的阶段性结果与剩余规格（`Probe.lean`／`Obstruction.lean`／`SingleLayer.lean`）

**（一）反驳方向：未找到反例。** `Obstruction.lean` 把搜索写成了可检查的形式：
`PUnit` 上的 16 张布尔真值表逐张列出（`(suppI, refutI)` 共 **256** 种全枚举）× 32 个关系式
（嵌套深度 ≤ 1）× 2 种赋值 = **16384** 组，先廉价筛选再全量验证 ⇒ **0 组通过**；
深度 2 的小池也为空。同时朴素候选族已被**整族排除**并给出机器验证的机制
（`not_forall_inf_eq_le`、`not_forall_sup_eq_eq` 是**反例**，`eq_of_inf_sup_eq` 是正确的排除工具）。

**（二）证明方向：单层情形已完整闭合**（`Probe.lean`／`SingleLayer.lean`／`SingleLayerFull.lean`）。

* 无条件结论（`Probe.lean`）：`⟦p⟧ = ⟦p'⟧`、`⟦v⟧ = ⟦v'⟧`——**不需要任何 `NoRel`**；
* 通用工具（`SingleLayer.lean`）：四个 **λ-探针** `andS`／`notAndS`／`notNotS`／`andNotS`
  （`¬` 写成显式箭头）＋ **`probe_pair`**／`pair_at`：对**任意** `S`，
  `S (S ⟦p⟧ ⟦q⟧) ⟦v⟧ = S (S ⟦p'⟧ ⟦q'⟧) ⟦v'⟧`（探针基；`probe_inner_eq` 是 `rfl`），
  只用 `probe_eq` ＋ 六次 `tbi_aux` ⇒ **零实例归约**；`P1_at`（`a ⊓ v` 区域）；
* 收尾（`SingleLayerFull.lean`）：**四个区域**——`a⊓v`（P₁）、`¬a⊓v`（P₂，探针 `notAndS`）、
  `¬a⊓¬v`（P₃，探针 `notNotS`）、`a⊓¬v`（P₄，探针 `andNotS`）——各自给出逐点 `↔`，
  合并得 `q_at` ⇒ `singleLayer_second`（`⟦q⟧ = ⟦q'⟧`）⇒ **`singleLayer_full`（三分量等式齐全）**。

**实现要点（反复卡住的那一处）**：先把 `holds` 展开成显式 `∧`／`→` **再**投影——
即先经 `andS_at`／`notAndS_at`／`notNotS_at`／`andNotS_at`（全部 `Iff.rfl`）拿到显式形状，
再做 `.1`／`.2` 与应用。直接对 `(notAndS A B).holds w` 做投影、在缺少期望类型时
elaborator 不肯归约；而经由 `↔` 引理则永远有明确类型。
（另注：把 `¬¬q ↔ ¬¬q'` 化成 `q ↔ q'` 需双重否定消去，本工程无 `by_contra` 策略，
用 `Classical.byContradiction` 自行补 `dne` 即可。）

**它的意义**：单层情形**严格强于** `cequiv_rel_components_of_noRel`——后者要求分量本身 `NoRel`，
这里的分量允许是 `p ⊳ q` 这种**关系式**（只要其参数 `NoRel`）。即**关系深度向上推进了一层**。

**诚实边界**：一般情形**不**随之关闭——那里的分量真值会**随 `suppI` 变化**，
`NoRel` 提供的基无关性不再可用（探针等式中的 `⟦p⟧_S` 变成 `S` 的函数），
上述代数推导失效。因此判决性尝试的**当前结论仍是"未决"**：
反驳搜索为空（`Obstruction.lean`，16384 组 0 反例）、证明方向已闭合到**深度 +1**。

### 6.11 第二模型族与关系自由区的无条件结果（`Strict.lean`／`NoRelFragment.lean`）

前面 §6.5–6.10 的所有不变量都要么禁用／限制 `E`、要么以 `TransferLemma` 为假设。
本节给出**第二条路线**，它**完全不经过** `TransferLemma`。

**（一）第二模型族（`Model/Strict.lean`）。** 定稿在 `Canonical.lean` 开头写道：
"语义不能退化为朴素的 `X ≤ Y` 蕴含读法（否则支持传递将成为有效式）"。本节把那个
**被拒绝的读法本身**做成结构并证明它**也是模型**：

```
严格蕴含框架：M.supp X φ ρ := X ≤ ⟦φ⟧_base          （无任何析取项）
              M.refut X φ ρ := X ⊓ ⟦φ⟧_base = ⊥ ∨ ⟦φ⟧_base = ⊤
```

| 定理 | 内容 |
|---|---|
| `strict_frame_truth` | 框架真值 = 基结构真值（与 `Canon.frame_truth` 逐支同构） |
| `strict_isModel` | **十三个字段逐一验证** ⇒ 任意非空 `W`、任意 `atomRel` 下都是模型 |
| `strict_transitivity_rule_valid` | 在该框架中支持传递的**规则形式成立** ⇒ 定稿那句设计理由成为**定理** |
| `strict_supp_le` | **全量 `Derivable`（含任意 `E`）** ⇒ `⟦p⟧ ≤ ⟦q⟧`（**无条件**） |

`strict_supp_le` 是本工程**第一条对全量 `Derivable` 无条件成立的支持-蕴含不变量**：
证明只有一行实质内容——`strict_isModel` ＋ `Derivable.soundness` 给出 `M ⊨ p ⊳ q`，
而 `M.supp` 按定义就是 `≤`（`Derivable.supp_of_valid`），再用 `strict_frame_truth` 搬回基结构层。
这也**定位了典范框架的困难所在**：`suppP` 的析取项 `Y = ⊤`（§6.1／`Disjuncts.lean` 指出它是
唯一破坏传递性的装置）；严格框架**没有这一项**，缺口随即消失。

**（二）关系自由桥（`Frontier/NoRelFragment.lean`）。** `truth_noRel_congr` 把
`NoRel`（分量中不出现 `⊳`／`⊲`）公式的真值证明为**与 `suppI`／`refutI` 的取法无关**
（`RestrictedE.truth_botBase_eq_canon` 与 `Transfer.truth_projBase₁_eq_canon` 都是它的特例）。
于是严格框架上的不等式可以**搬到典范框架**：

| 路线 | 片段／假设 | 结论 |
|---|---|---|
| `EFree.noE_supp_le` | 禁用 `E`，任意公式 | 典范框架上 `⟦p⟧ ≤ ⟦q⟧` |
| `RestrictedE.supp_le₁_canon` | 受限 `E`（源公式 `NoRel`），任意公式 | 同上 |
| `Conditional.supp_le_of_transferLemma_canon` | 全量 `Derivable` ＋ **假设 `TransferLemma`** | 同上 |
| **`supp_le_canon_of_noRel`** | **全量 `Derivable`（无假设）**，`p`、`q` 都 `NoRel` | 同上 |
| **`strict_supp_le`** | **全量 `Derivable`（无假设）**，任意公式，在**严格框架**上 | 严格框架上 |

四条路线**互不包含**：本节用"分量关系自由"换掉了 `TransferLemma` 假设，而不是推出它。

**（三）两条障碍的收窄。** 由 `strict_supp_le` 沿两条前提**串联**（`strict_supp_le_trans`）得
`transitivity_le_canon_of_noRel`：**中间公式 `b` 不需要关系自由**。于是（全部**无条件**）：

| 定理 | 内容 |
|---|---|
| `transitivity_le_canon_of_noRel` | `a`、`c` 都 `NoRel` ⇒ `⟦a⟧ ≤ ⟦c⟧`（典范基结构；**`b` 任意**） |
| `transitivity_valid_canon_of_noRel` | 同上 ⇒ `a ⊳ c` 在**一切**典范框架中有效 |
| `s7_valid_canon_of_noRel` | 四条分量都 `NoRel` ⇒ `(a ∧ b) ⊳ (φ ∧ ψ)` 在一切典范框架中有效 |
| `countermodel_needs_rel` | 支持传递的典范框架反模型 ⇒ **结论的分量** `a` 或 `c` **必须**含关系子公式（`b` 不受限） |
| `s7_countermodel_needs_rel` | S7 同理：结论的两个分量 `a∧b`、`φ∧ψ` 不可能都关系自由 |

**与既有障碍的关系**：`NonAdmissible.lean` 第十一节给的是**真值形状**的限制
（反例处 `⟦b⟧ = ⊤` 且 `⟦c⟧ ≠ ⊤`），本节给的是**语法形状**的限制（**结论**分量必须出现关系子公式）。
两者**互相独立**，可同时施加于任何反例。**第三条**（§6.12 的阈值族给出）是**跨模型**的：
若中间公式 `b` 关系自由，则反例处每个非典范阈值模型都迫使 `⟦c⟧_{th_U} = ⊤`
（`canon_middle_noRel_supported_top_in_threshold`）——若 `c` 关系自由，这与 `⟦c⟧_C ≠ ⊤` 直接矛盾。

**诚实边界**：本节**没有**攻下账本中剩下的两条。它把窗口**关小**了
（任何反例都必须同时满足上述两条必要条件），但 `NoRel` 是**结论分量**上的**强语法限制**，
一般情形（结论分量含关系子公式）**仍然归约到** `TransferLemma`／相合性公开问题。
另外，严格蕴含框架**验证**的规则更多（例如支持传递），因此它**不能**用来构造任何 N3 反例
——它对 N3 账本的作用只在于「把困难定位到 `suppP` 的哪个析取项上」。

### 6.12 第三个模型族：阈值族（`Threshold.lean`）

把 `suppP` 的析取项 `X = ⊤` **一般化为任意固定阈值** `U`：

```
thSuppP U X Y  :=  X ≤ Y  ∨  X = U  ∨  Y = ⊤            -- X ⊳ Y
thRefutP U X Y :=  X ⊓ Y = ⊥  ∨  X = U  ∨  Y = ⊤        -- X ⊲ Y
```

`U = ⊤` 时它与 `Canon.suppP`／`Canon.refutP` 只差一个**冗余**的 `Y = ⊥`
（`Structure.refutP_iff_disjoint_or_top`），故本族是典范判据的直接一般化。

| 定理 | 内容 |
|---|---|
| `thSuppP_inf`／`_and`／`_iInter`／`_of_iInter`、`thRefutP_inf`／`_and`／`_iInter`／`_of_iInter`、`thRefutP_of_thSuppP_compl` | 九条规则的语义闭包条件（逐支同构于 `Canonical.lean`，只把 `X = ⊤` 换成 `X = U`） |
| `th_isModel` | **对任意非空 `W`、任意 `atomRel`、任意 `U`** 都是模型（十三字段逐一验证，**不用**可靠性反推） |
| `th_supp_le` | **每阈值一条**不变量：全量 `Derivable` ⇒ `⟦p⟧ρ ≤ ⟦q⟧ρ ∨ ⟦p⟧ρ = U ∨ ⟦q⟧ρ = ⊤` |
| `thSuppP_not_transitive` | **零公理**：`X ≤ U`、`X ≠ U`、`X ≰ Z`、`Z ≠ ⊤` ⇒ `thSuppP U X U ∧ thSuppP U U Z ∧ ¬ thSuppP U X Z` |
| `ThWitness.witness` | 具体见证（`Fin 3`，阈值 `U = {0,1} ≠ ⊤`），只需 `propext` |
| `canon_middle_noRel_supported_top_in_threshold` | 与典范框架的障碍**联用**（见 §6.11）：`b` 关系自由且 `⟦b⟧_C = ⊤` 时，**每个** `U ≠ ⊤` 都迫使 `⟦c⟧_{th_U} = ⊤` |

**意义（一处措辞修正）**：`Structure.lean` 的表格与 README 曾写"支持侧 `X = ⊤` 是**唯一**
破坏传递性的装置"。阈值族给出反例：**对任意 `U`**，只要支持者恰为 `U` 就能破坏传递性
（`U = ⊤` 时即 `Canon.suppP_not_transitive`，而 `U = {0,1}` 时阈值根本不是 `⊤`）。
准确的说法是：破坏传递性的是**"支持者恰等于某个固定阈值"这一形状**，
而不是 `⊤` 这个具体集合。（详见 [`讨论与局限.md`](讨论与局限.md) §7.7。）

**诚实边界**：本族**只给必要条件**，**不**给任何反例——与 `strictFrame` 一样，
它验证了许多被定稿拒绝的规则（支持传递在本族中也成立）。`thSuppP` 不传递**只说明这个关系不是预序**；
要成为 N3 反例仍需**可推导的**两个前提，那正是尚未解决的部分。
